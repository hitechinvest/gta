# РАЙОНЫ — сетевая браузерная 3D мини-GTA

Многопользовательская 3D-игра в браузере в духе GTA, действие происходит в
российском городе: панельные микрорайоны, сталинки в центре, промзона с
трубами, гаражные кооперативы, частный сектор, площадь с памятником и храмом.
Можно ходить, угонять «Жигули» и «Буханку», стрелять, сбивать уровень розыска
и убегать от патрулей ДПС.

Всё рисуется процедурно на Three.js — ни одной внешней картинки, модели или
звукового файла: текстуры фасадов и асфальта генерируются на canvas, звуки
синтезируются через WebAudio, город строится из seed.

## Быстрый старт

```bash
npm install
npm start
```

Откройте http://localhost:3000 — и позовите друзей на тот же адрес
(в локальной сети это `http://<ваш-IP>:3000`). Все, кто зашёл, попадают
в один общий город.

Переменные окружения:

| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| `PORT` | порт HTTP/WebSocket | `3000` |
| `HOST` | адрес прослушивания | `0.0.0.0` |
| `SEED` | seed генерации города | `20250815` |

Смена `SEED` полностью меняет планировку города — дома, дворы, точки спавна
машин и бонусов.

## Управление

| Действие | Клавиши |
| --- | --- |
| Движение | `W` `A` `S` `D`, бег — `Shift` |
| Камера | мышь, прицел — правая кнопка |
| Огонь | левая кнопка |
| Сесть в машину / выйти | `F` |
| Прыжок / ручник в машине | `Пробел` |
| Оружие | `1`–`4`, колесо мыши, перезарядка — `R` |
| Чат | `T` или `Enter` |
| Таблица игроков | `Tab` |
| Режим миникарты | `M` |
| Сигнал / фары | `H` / `L` |

На телефоне и планшете появляются джойстик и кнопки: левый стик — движение,
свайп по экрану — камера, кнопки справа — огонь, прицел, посадка в машину,
прыжок и тормоз.

## Что есть в игре

- **Город из seed.** Кварталы разных типов: центральная площадь с памятником и
  храмом, сталинки с арками и вывесками, спальные микрорайоны с качелями и
  ковровыбивалками, заводские корпуса с трубами, гаражи, частный сектор.
- **Транспорт.** «Жигули», «Волга», «Нива», УАЗ «Буханка», «Газель» и машины
  ДПС. Аркадная физика с заносом, ручником, повреждениями и взрывами.
- **Оружие.** Кулаки, ПМ, АК-74 и обрез (дробь с разбросом). Хедшоты, трассеры,
  вспышки, гильзы-искры, следы крови.
- **Розыск.** Стрельба, наезды и угон повышают уровень (до пяти звёзд).
  Патрули ДПС выезжают на перехват, едут по улицам и стреляют. Без нарушений
  розыск постепенно спадает.
- **Мультиплеер.** Общий мир, синхронизация игроков и машин, чат, килл-фид,
  таблица с убийствами и пингом.
- **Прохожие.** Ходят по тротуарам, разбегаются от выстрелов, попадают под
  колёса (за это дают звезду розыска).
- **Смена суток.** Полный цикл за 10 минут: вечерний свет, ночью зажигаются
  окна, фонари и фары.
- **Бонусы.** Аптечки, бронежилеты, оружие и деньги, которые респавнятся.

## Как это устроено

```
server/
  index.js      HTTP + WebSocket, раздача статики
  room.js       игровая комната: игроки, транспорт, урон, ИИ ДПС, розыск
shared/
  worldgen.js   детерминированная генерация города (сервер и клиент)
  protocol.js   константы: оружие, машины, тайминги, розыск
public/js/
  main.js       сцена, игровой цикл, стрельба, сетевые события
  city.js       сборка города из мешей (слияние геометрии, инстансы)
  models.js     процедурные модели людей, машин и уличных объектов
  textures.js   canvas-текстуры фасадов, асфальта, вывесок
  player.js     локальный игрок и камера от третьего лица
  vehicle.js    физика машины и интерполяция чужих машин
  remote.js     отрисовка других игроков
  peds.js       прохожие
  effects.js    трассеры, искры, кровь, взрывы, дым
  audio.js      синтез звука через WebAudio
  hud.js        интерфейс, чат, килл-фид, таблица
  minimap.js    миникарта
  input.js      клавиатура, мышь, сенсорное управление
  net.js        обёртка над WebSocket
```

**Модель синхронизации.** Позицию персонажа и машины считает клиент и шлёт
серверу 20 раз в секунду; сервер рассылает снапшоты тоже 20 Гц, чужие сущности
интерполируются с задержкой 100 мс. Здоровье, урон, деньги, розыск, ДПС,
владение машинами и бонусы считает сервер: попадания проверяются по дистанции,
трассировке через стены и лимиту частоты выстрелов, поэтому клиент не может
просто «объявить» убийство.

`shared/worldgen.js` — один и тот же модуль для Node и браузера: сервер шлёт
только seed, а коллизии, дороги и точки спавна обе стороны считают одинаково.

## Требования

Node.js 18+ и браузер с WebGL 2 и ES-модулями. Зависимости: `express`, `ws`,
`three` (билд three.js копируется в `public/vendor` на `npm install`).
