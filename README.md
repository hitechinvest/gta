# РАЙОНЫ — сетевая браузерная 3D мини-GTA

Многопользовательская 3D-игра в браузере в духе GTA. По умолчанию действие
происходит в настоящем центре Йошкар-Олы: дома выдавлены из реальных контуров
OpenStreetMap, улицы проложены по осевым линиям, через город течёт Малая
Кокшага, а на местах стоят кремль, соборы, башни с часами и фламандская
набережная Брюгге. Можно ходить, угонять машины, стрелять, сбивать уровень
розыска и убегать от патрулей ДПС.

Геометрия, звук и большая часть текстур делаются на лету: фасады и асфальт
рисуются на canvas, звуки синтезируются через WebAudio. Извне подключены
только свободно лицензированные материалы — данные OpenStreetMap (ODbL),
модели машин и людей Quaternius (CC0), фотофактуры ambientCG (CC0) и
фотографии зданий Йошкар-Олы с Викисклада (см. `public/models/README.md`,
`public/textures/buildings/CREDITS.md`, `public/textures/facades/LICENSE.txt`).

Процедурный город никуда не делся: он собирается из seed и включается
переменной `CITY=procedural`.

## Быстрый старт

```bash
npm install
npm start
```

Откройте http://localhost:3000 — и позовите друзей на тот же адрес
(в локальной сети это `http://<ваш-IP>:3000`). Все, кто зашёл, попадают
в один общий город.

Переменные окружения:

| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| `PORT` | порт HTTP/WebSocket | `3000` |
| `HOST` | адрес прослушивания | `0.0.0.0` |
| `SEED` | seed генерации города | `20250815` |
| `CITY` | `procedural` — вернуться к городу из seed | реальный центр |

Смена `SEED` полностью меняет планировку процедурного города — дома, дворы,
точки спавна машин и бонусов. На реальном центре seed ни на что не влияет.

Выгрузка OSM лежит в репозитории (`shared/city-osm.json`), в рантайме игра
никуда не ходит. Обновить или расширить её:

```bash
node scripts/fetch-osm.js --radius 1500
```

## Развёртывание на сервере (Ubuntu + nginx)

На сервере с nginx игра ставится одним скриптом: он поднимает systemd-сервис,
пишет vhost с проксированием WebSocket и выпускает сертификат Let's Encrypt.

```bash
sudo -i
git clone -b claude/3d-browser-minigame-9b0qly \
    https://github.com/hitechinvest/gta.git /opt/rayony
cd /opt/rayony
bash deploy/install.sh myonlinegame.gdesite.ru 3210
```

Первый аргумент — домен (нужна A-запись или wildcard на IP сервера), второй —
внутренний порт Node (наружу не выставляется, nginx проксирует на него
`127.0.0.1`). Скрипт идемпотентен: повторный запуск обновляет сервис и конфиг.

Обновление после новых коммитов:

```bash
cd /opt/rayony && git pull && npm ci --omit=dev && systemctl restart rayony
```

Полезное: `systemctl status rayony`, `journalctl -u rayony -f`,
`curl -s https://myonlinegame.gdesite.ru/api/status`.

## Управление

| Действие | Клавиши |
| --- | --- |
| Движение | `W` `A` `S` `D`, бег — `Shift` |
| Камера | мышь, прицел — правая кнопка |
| Огонь | левая кнопка |
| Сесть в машину / выйти | `F` |
| Прыжок / ручник в машине | `Пробел` |
| Оружие | `1`–`4`, колесо мыши, перезарядка — `R` |
| Чат | `T` или `Enter` |
| Таблица игроков | `Tab` |
| Режим миникарты | `M` |
| Сигнал / фары | `H` / `L` |

На телефоне и планшете появляются джойстик и кнопки: левый стик — движение,
свайп по экрану — камера, кнопки справа — огонь, прицел, посадка в машину,
прыжок и тормоз.

## Что есть в игре

- **Настоящий центр города.** 2500 домов по контурам OSM с этажностью, формой
  и цветом кровли из тегов, названиями и адресами на табличках; парки и
  скверы по своим контурам, река Малая Кокшага, фонари вдоль проезжих улиц.
- **Ориентиры.** Царевококшайский кремль с зубцами и шатровыми башнями,
  Благовещенская и Спасская башни с циферблатами, соборы с золотыми главами,
  замок театра кукол, ряд уступчатых фронтонов набережной Брюгге. Всё стоит
  на своих настоящих местах — координаты из OSM.
- **Фотофасады.** У части домов центра на стенах их собственные фотографии с
  Викисклада, у остальных — процедурные фасады поверх фотофактур кирпича и
  штукатурки.
- **Транспорт.** «Жигули», «Волга», «Нива», УАЗ «Буханка», «Газель», машины
  ДПС плюс иностранные модели Quaternius. Аркадная физика в духе GTA: газ
  бодрее на низах, `S` сначала тормозит и только потом включает задний ход,
  ручник срывает корму в занос, руль сам возвращается в ноль.
- **Дорожное движение.** Машины едут по реальным полосам, не проходят сквозь
  друг друга: на встречном ударе останавливаются, дымят, на сильном — горят.
  Из поля зрения игрока не исчезают.
- **Прохожие и двухколёсные.** Люди ходят по настоящим тротуарам с
  анимацией из общего набора клипов; самокатчики и мотоциклисты едут по своим
  сетям, а за езду вдвоём на одном самокате их ловит полиция.
- **Оружие.** Кулаки, ПМ, АК-74 и обрез (дробь с разбросом). Хедшоты, трассеры,
  вспышки, гильзы-искры, следы крови.
- **Розыск.** Стрельба, наезды и угон повышают уровень (до пяти звёзд).
  Патрули ДПС ищут дорогу по графу улиц алгоритмом A*, выезжают на перехват и
  стреляют. Без нарушений розыск постепенно спадает.
- **Мультиплеер.** Общий мир, синхронизация игроков и машин, чат, килл-фид,
  таблица с убийствами и пингом.
- **Смена суток.** Полный цикл за 10 минут: вечерний свет, ночью зажигаются
  окна, фонари и фары.
- **Бонусы.** Аптечки, бронежилеты, оружие и деньги у стен домов и в парках.

## Как это устроено

```
server/
  index.js      HTTP + WebSocket, раздача статики
  room.js       игровая комната: игроки, транспорт, урон, ИИ ДПС, розыск
shared/
  worldgen.js   детерминированная генерация города (сервер и клиент)
  osmworld.js   мир из выгрузки OSM в том же формате, что процедурный
  roadnet.js    граф улиц: маршруты пешеходов, самокатов и патрулей (A*)
  landmarks.js  знаковые здания процедурного города
  city-osm.json выгрузка центра Йошкар-Олы (ODbL)
  protocol.js   константы: оружие, машины, тайминги, розыск
public/js/
  main.js       сцена, игровой цикл, стрельба, сетевые события
  city.js       сборка процедурного города (слияние геометрии, инстансы)
  osmcity.js    сборка реального центра: дома, кровли, вода, зелень, фонари
  landmarks3d.js фасады и надстройки ориентиров (кремль, башни, фронтоны)
  models.js     процедурные модели людей, машин и уличных объектов
  textures.js   canvas-текстуры фасадов, асфальта, вывесок
  player.js     локальный игрок и камера от третьего лица
  vehicle.js    физика машины и интерполяция чужих машин
  remote.js     отрисовка других игроков
  peds.js       прохожие
  riders.js     самокатчики и мотоциклисты
  traffic.js    городской поток машин, аварии и пожары
  effects.js    трассеры, искры, кровь, взрывы, дым
  audio.js      синтез звука через WebAudio
  hud.js        интерфейс, чат, килл-фид, таблица
  minimap.js    миникарта
  input.js      клавиатура, мышь, сенсорное управление
  net.js        обёртка над WebSocket
scripts/
  fetch-osm.js       выгрузка города из Overpass API в city-osm.json
  facade-tool.js     сборка фасадных текстур из фотографий
  models-to-glb.js   конвертация FBX/OBJ в GLB (модели машин и людей)
```

**Фасады из фотографий.** `scripts/facade-tool.js` превращает снимок дома в
текстуру стены: находит небо по цвету и отсутствию фактуры и срезает его,
ищет полосу фасада по окнам (иначе полкадра занимают дорога и газон),
исправляет скос кадра подбором наклона, при котором ряды окон встают
горизонтально, и обрезает результат по целому числу этажей. Рядом пишется
`facades.json` — размер плитки в метрах, число этажей, автор и лицензия.
Снимки с остатками неба, зеленью во весь кадр или без окон отбраковываются:
такому дому достаётся процедурный фасад.

```bash
node scripts/facade-tool.js fetch   # скачать оригиналы с Викисклада
npm run facades                     # собрать текстуры и facades.json
```

Источники — только свободные лицензии. Снимки Яндекс.Карт и Google Maps
подключать нельзя: их условия запрещают выгрузку и производные работы.

**Модель синхронизации.** Позицию персонажа и машины считает клиент и шлёт
серверу 20 раз в секунду; сервер рассылает снапшоты тоже 20 Гц, чужие сущности
интерполируются с задержкой 100 мс. Здоровье, урон, деньги, розыск, ДПС,
владение машинами и бонусы считает сервер: попадания проверяются по дистанции,
трассировке через стены и лимиту частоты выстрелов, поэтому клиент не может
просто «объявить» убийство.

`shared/worldgen.js` и `shared/osmworld.js` — одни и те же модули для Node и
браузера: сервер шлёт только seed (или признак реального города), а коллизии,
дороги и точки спавна обе стороны считают одинаково. Коллизии с домами
считаются по настоящему контуру, а не по габаритному прямоугольнику: у
Г-образного дома прямоугольник перекрывал проезжую часть.

**Дальность прорисовки.** Машины и мелочь скрываются дальше 170 метров, а
подписи домов — дальше 220: на полном городе это снимает примерно половину
вызовов отрисовки.

## Требования

Node.js 18+ и браузер с WebGL 2 и ES-модулями. Зависимости: `express`, `ws`,
`three` (билд three.js копируется в `public/vendor` на `npm install`).

## Источники и лицензии

Код игры — часть репозитория. Внешние материалы подключены только под
свободными лицензиями, файлы с полным перечнем авторов лежат рядом с самими
материалами:

| Что | Источник | Лицензия | Где перечислено |

| Контуры домов, улицы, река, зелень | OpenStreetMap | ODbL | `shared/city-osm.json` (поле `source`) |
| Модели машин и людей | Quaternius | CC0 | `public/models/cars/LICENSE.txt`, `public/models/people/LICENSE.txt` |
| Фотофактуры кирпича и штукатурки | ambientCG | CC0 | `public/textures/facades/LICENSE.txt` |
| 30 фотографий фасадов Йошкар-Олы | Wikimedia Commons | CC BY-SA и CC BY | `public/textures/buildings/CREDITS.md` |

Фотографии с Викисклада — под share-alike, поэтому производные текстуры в
`public/textures/buildings` распространяются на тех же условиях, а авторы,
лицензии и ссылки на исходные снимки перечислены в `CREDITS.md`.
