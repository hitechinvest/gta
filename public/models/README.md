# Внешние модели

Каталог необязателен: без него игра рисует всё процедурно.

Чтобы подключить готовые модели (например, CC0 с Mixamo, Quaternius или
Kenney), положите сюда `.glb` и создайте `manifest.json`:

```json
{
  "characters": {
    "ped": {
      "url": "ped.glb",
      "scale": 1,
      "yaw": 0,
      "clips": { "idle": "Idle", "walk": "Walk", "run": "Run", "aim": "Aim" }
    }
  },
  "vehicles": {
    "zhiguli": { "url": "vaz2106.glb", "scale": 1, "yaw": 3.14159 }
  }
}
```

- `scale` — множитель, если модель сделана в других единицах;
- `yaw` — доворот, если модель смотрит не в сторону +Z;
- `clips` — соответствие состояний игры именам анимаций внутри файла.

Модели со скелетом подхватываются вместе с анимациями: движок сам
переключает клипы по состоянию персонажа. Без анимаций модель просто
стоит, а конечности не двигаются.

## Что лежит сейчас

- `cars/` — Quaternius «Cars» (CC0): семь иномарок с настоящими пропорциями,
  раздельными колёсами и материалами кузова, стёкол и оптики;
- `people/` — Quaternius «Animated Men/Women» (CC0): восемь персонажей,
  анимации вынесены в `animations.glb` — скелет у всех общий, и держать по
  копии клипов в каждом файле значило бы возить лишние мегабайты.

Исходники (FBX и OBJ) переводятся в GLB скриптом
`node scripts/models-to-glb.js <исходники> <куда> --height 1.8`. Он же
склеивает куски геометрии по материалам, склеивает совпадающие вершины,
переносит точку вращения колеса в его центр и приводит рост персонажа к
метрам по костям.

Машины подгоняются под габариты из `shared/protocol.js` по длине и ширине:
масштаб в манифесте задавать не нужно, картинка и коллизии совпадают сами.
